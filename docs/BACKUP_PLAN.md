# LinkLazy — ব্যাকআপ ও পুনরুদ্ধার পরিকল্পনা (Batch 21)

> লক্ষ্য: ডাটাবেস নষ্ট, ভুল ডিলিট বা অ্যাকাউন্ট-সমস্যায় যেন ব্যবসার টাকা-হিসাব ও ব্যবহারকারীর ডাটা হারিয়ে না যায়।
> ⚠️ প্ল্যানভেদে Supabase/Vercel-এর সুবিধা বদলায় — নিচের "যাচাই" ধাপগুলো আপনার নিজের ড্যাশবোর্ডে মিলিয়ে নিন।

## ১. কী কোথায় থাকে, আর তার ব্যাকআপ কীভাবে

| জিনিস | কোথায় | ব্যাকআপ |
|---|---|---|
| কোড | GitHub (linklazy-main) | GitHub নিজেই; তবুও মাসে একবার ZIP ডাউনলোড করে আপনার কম্পিউটারে রাখুন |
| ডাটাবেস (ব্যবহারকারী, অর্ডার, ওয়ালেট, লেজার) | Supabase | **নিচে ২ ও ৩ নম্বর** |
| ফাইল (avatars ইত্যাদি) | Supabase Storage | ডাটাবেস-ব্যাকআপে **থাকে না** — ৪ নম্বর দেখুন |
| গোপন চাবি (API key, secret) | Vercel > Settings > Environment Variables | ৫ নম্বর দেখুন |
| ইমেইল ডোমেইন/DNS | ডোমেইন-রেজিস্ট্রার + Resend | DNS রেকর্ডের স্ক্রিনশট রাখুন |

## ২. Supabase-এর নিজস্ব ব্যাকআপ (প্রথম সুরক্ষা)
1. Supabase ড্যাশবোর্ড > **Database > Backups** খুলুন।
2. দেখুন আপনার প্ল্যানে **দৈনিক ব্যাকআপ** আছে কিনা ও কত দিন রাখে। (সাধারণত Pro প্ল্যানে দৈনিক ব্যাকআপ কয়েক দিন রাখা হয়; Free প্ল্যানে এই সুবিধা না-ও থাকতে পারে — আপনার ড্যাশবোর্ড যা বলে সেটাই সত্য।)
3. টাকা-পয়সার ডাটা (ওয়ালেট, লেজার, উইথড্রয়াল) থাকায় **লঞ্চের আগে অবশ্যই এমন প্ল্যান নিন যাতে স্বয়ংক্রিয় ব্যাকআপ আছে** (Vercel Pro-র সাথে একসাথে ভাবুন)।
4. **Point-in-Time Recovery (PITR)** একটি পেইড অ্যাড-অন: "গতকাল দুপুর ২টার অবস্থায় ফিরে যাও" ধরনের পুনরুদ্ধার দেয়। টাকা-লেনদেন বাড়লে নিন; শুরুতে দৈনিক ব্যাকআপ + সাপ্তাহিক নিজের ডাম্প যথেষ্ট।

## ৩. নিজের হাতে সাপ্তাহিক ডাম্প (দ্বিতীয় সুরক্ষা — Supabase-এর বাইরে একটি কপি)
Supabase প্রোভাইডারের বাইরে কপি না থাকলে সেই প্রোভাইডারের সমস্যায় সব যায়। তাই সপ্তাহে একবার:
1. Supabase > Project Settings > **Database > Connection string** থেকে URI কপি করুন (পাসওয়ার্ডসহ; এটি গোপন রাখুন, চ্যাটে/GitHub-এ দেবেন না)।
2. আপনার কম্পিউটারে (PostgreSQL client tools ইনস্টল থাকলে):
   ```
   pg_dump "<CONNECTION_STRING>" --no-owner --no-privileges -Fc -f linklazy-YYYY-MM-DD.dump
   ```
3. ফাইলটি **দুই জায়গায়** রাখুন (যেমন আপনার কম্পিউটার + একটি এনক্রিপ্টেড ক্লাউড ফোল্ডার)। শেষ ৪ সপ্তাহের কপি রাখুন, পুরোনোগুলো মুছুন।
4. কম্পিউটারে client tools না থাকলে বিকল্প: Supabase ড্যাশবোর্ড > Table Editor থেকে গুরুত্বপূর্ণ টেবিল (`profiles`, `orders`, `payments`, `wallet_ledger`, `withdrawal_requests`, `wallet_bonuses`) CSV এক্সপোর্ট — এটি দ্বিতীয় সেরা, পূর্ণ ডাম্প নয়।

## ৪. Storage (ফাইল)
- ডাটাবেস-ব্যাকআপে বাকেটের ফাইল থাকে না। এখন বাকেট `avatars` (পাবলিক ছবি); হারালে ব্যবহারকারীরা আবার আপলোড করতে পারে, তাই ঝুঁকি কম।
- ভবিষ্যতে গুরুত্বপূর্ণ ফাইল (প্রমাণ, ডকুমেন্ট) আপলোড শুরু হলে মাসে একবার বাকেট ডাউনলোড করার নিয়ম এখানে যোগ করুন।

## ৫. গোপন চাবির নিরাপদ তালিকা
- Vercel > Settings > Environment Variables-এর **নামগুলোর তালিকা** (মান নয়) `.env.example`-এ আছে — ওটা আপডেট রাখুন।
- মানগুলো একটি **পাসওয়ার্ড ম্যানেজারে** (Bitwarden/1Password) রাখুন। কখনো GitHub/ইমেইলে নয়।
- দরকারি চাবি: Supabase (URL, anon, service role), PayPal (client id/secret, **PAYPAL_WEBHOOK_ID**), bKash, Resend (API key, EMAIL_FROM), CRON_SECRET, Ahrefs, AI প্রোভাইডার, Saleshandy।

## ৬. পুনরুদ্ধারের মহড়া (কাগজে নয়, সত্যি করে) — লঞ্চের আগে একবার, পরে ৩ মাসে একবার
1. Supabase-এ একটি **নতুন খালি টেস্ট প্রজেক্ট** খুলুন (আসল প্রজেক্টে কিছু ঢালবেন না)।
2. সাপ্তাহিক ডাম্প সেখানে রিস্টোর করুন: `pg_restore --no-owner -d "<TEST_CONNECTION_STRING>" linklazy-YYYY-MM-DD.dump`
3. টেস্ট প্রজেক্টে দেখুন: ব্যবহারকারী সংখ্যা, `wallet_ledger` সারি সংখ্যা ও একটি অ্যাকাউন্টের ব্যালেন্স আসল প্রজেক্টের সাথে মেলে কিনা।
4. মিললে ✅ — তারিখসহ নিচের লগে লিখুন। না মিললে আমাকে ফলাফল দিন।
5. টেস্ট প্রজেক্ট মুছে ফেলুন।

## ৭. বিপদের সময় কী করবেন (সংক্ষেপে)
- **ভুল ডিলিট/ভুল স্ক্রিপ্ট:** সাথে সাথে সাইট-লেখা বন্ধ ভাবুন (Admin > Settings-এ সাইনআপ/পেমেন্ট বন্ধ), তারপর Supabase দৈনিক ব্যাকআপ/PITR থেকে ফিরে যান। আমাকে বলুন কী ঘটল।
- **Supabase সার্ভিস বন্ধ:** Supabase Status পেজ দেখুন; সাপ্তাহিক ডাম্প থেকে নতুন প্রজেক্টে রিস্টোর করে `NEXT_PUBLIC_SUPABASE_URL` ইত্যাদি Vercel-এ বদলান (শেষ উপায়)।
- **চাবি ফাঁস সন্দেহ:** সংশ্লিষ্ট সার্ভিসে (PayPal/Supabase/Resend ইত্যাদি) নতুন চাবি বানিয়ে পুরোনোটি বাতিল করুন, Vercel-এ নতুনটি বসিয়ে Redeploy।
