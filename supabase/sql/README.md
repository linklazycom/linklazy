## টেস্ট
- টেস্ট অর্ডার: accept → সেলারের ওয়ালেটে টাকা, `payments` সারি `released`
- অ্যাডমিন থেকে একটি টেস্ট ওয়ালেট-অর্ডারে **Cancel**/**Refund** → ক্রেতার ওয়ালেটে টাকা ফেরত আসে (লেজারে "Refund — ..." এন্ট্রি)
- অ্যাডমিন থেকে **Force accept** → সেলারের ওয়ালেটে টাকা যায়
- ডিসপিউট খুলুন (ক্রেতা/সেলার অ্যাকাউন্ট থেকে) → এখন কাজ করে; অ্যাডমিন থেকে resolve → দ্বিতীয়বার resolve করা যায় না
- একটি PPV আনলক করুন → লেজারে `unlock_spend` (৮০%) + `platform_fee` (২০%), যোগফল = মূল্য
- অ্যাডমিন লগ: একটি সাইট approve/reject করে `admin_logs` টেবিলে সারি এসেছে কিনা
